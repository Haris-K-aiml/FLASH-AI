# Flash AI – AI Chatbot

## Introduction

Flash AI is an AI-powered chatbot designed to interact with users and provide helpful responses to their questions. The application uses a web-based interface connected to an AI backend.

## Features

- Interactive chatbot interface
- Real-time user and AI messages
- AI-powered responses
- Simple and user-friendly design
- Flash AI identity and personality
- Backend API integration
- Responsive web interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenAI API
